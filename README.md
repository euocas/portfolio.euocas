## 📌 Sobre o projeto

Este projeto foi desenvolvido como um portfólio digital para reunir projetos profissionais e apresentar minha experiência na área de design.

O site possui uma interface responsiva, navegação por seções e uma área de contato para facilitar a comunicação com possíveis clientes, empresas e parceiros.

### Principais seções

* 🏠 **Início** — apresentação profissional
* 👤 **Sobre** — informações sobre experiência e perfil
* 🎨 **Projetos** — apresentação dos trabalhos realizados
* 💼 **Habilidades** — ferramentas e competências
* 📩 **Contato** — canais para comunicação profissional
